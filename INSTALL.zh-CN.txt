双AI对话台 安装说明
====================

同一个问题同时问 Claude 和 ChatGPT（Codex），并排看两份回答，自动对比打分、生成可视化报告。
用的是你自己的订阅，不按次计费。所有对话都保存在你自己的电脑上。


【需要准备】
- Windows 10 或 11 电脑，能上网
- Claude 订阅账号（Pro 或 Max）
- ChatGPT 订阅账号（Plus / Pro 等能用 Codex 的）
- 不需要提前装任何软件，也不需要管理员权限


【安装（大约 5~15 分钟，看网速）】
1. 从 GitHub 的 Releases 页面下载 dual-ai-chat-v<版本>.zip，解压到一个固定的位置，例如 D:\dual-ai-chat
   注意：要先「全部解压缩」，不要在压缩包里直接双击运行。

2. 打开解压出来的 dual-ai-chat 文件夹，双击 install.bat。
   - 如果 Windows 提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
   - 它会自动下载 Node.js、Claude Code、Codex，全部放在这个文件夹的 runtime 里，不改系统。

3. 中途会打开两次浏览器，需要你登录：
   - 第一次：登录 Claude 订阅账号，按页面提示「授权」。
   - 第二次：选「Sign in with ChatGPT」，登录 ChatGPT 账号。
   每次登录完回到黑色窗口，它会自动继续。

4. 会问要不要装两个可选功能，建议都按回车（Y）：
   - PDF / Word / Excel 读取（约 60 MB）
   - iPhone 照片 HEIC 格式支持（约 100 MB）

5. 看到「全部完成！」就装好了，会自动打开。桌面上会出现「双AI对话台」图标。


【日常使用】
- 打开：双击桌面的「双AI对话台」（或文件夹里的 start.vbs）。
- 提问：选「只问 Claude」「只问 Codex」或「两个都问 · 对比」，Enter 发送。
- 附件：图片、截图、iPhone 照片、PDF、Word、Excel、CSV 可以直接拖进窗口，或 Ctrl+V 粘贴截图。
- 回看：左边按日期（有日历）或按话题找以前的对话，也可以搜索。
- 界面语言：左下角可以切换 中文 / 日本語 / English。


【常见问题】
- 出错或中途断网：再双击一次 install.bat，它会检查缺什么补什么，装好的不会重装。
  安装日志在 data\install.log。
- 提示没有登录 / 登录过期：再双击一次 install.bat，它会重新打开登录页。
- 关闭后台服务：界面左下角「设置与连接」→「关闭后台服务」。
- 卸载：先关闭后台服务，再删除整个文件夹和桌面图标即可。
  （登录信息保存在 C:\Users\你的用户名\.claude 和 .codex 里，不想保留也可以删掉。）


【隐私】
对话、附件、对比报告都只保存在这个文件夹的 data 里，不会上传到别处
（提问内容当然会发给 Claude / ChatGPT 来回答）。
