デュアルAIチャット インストール手順
==================================

同じ質問を Claude と ChatGPT（Codex）に同時に聞き、2つの回答を並べて表示、自動で採点・比較して
ビジュアルなレポートを作ります。あなた自身のサブスクを使うので従量課金はありません。
会話はすべてあなたのパソコンの中だけに保存されます。


【必要なもの】
- インターネットにつながる Windows 10 / 11 のパソコン
- Claude のサブスク（Pro または Max）
- Codex が使える ChatGPT のサブスク（Plus / Pro など）
- 事前のソフトのインストールや管理者権限は不要です


【インストール（回線速度により 5〜15 分ほど）】
1. GitHub の Releases ページから dual-ai-chat-v<バージョン>.zip をダウンロードし、
   決まった場所（例：D:\dual-ai-chat）に展開します。
   注意：必ず「すべて展開」してから使ってください。zip の中から直接実行しないでください。

2. 展開した dual-ai-chat フォルダを開き、install.bat をダブルクリックします。
   - 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。
   - Node.js・Claude Code・Codex を自動でダウンロードし、このフォルダの runtime に入れます。
     システムには何もインストールしません。

3. 途中でブラウザが 2 回開くので、ログインしてください：
   - 1 回目：Claude のサブスクのアカウントでログインし、画面の指示どおり「許可」します。
   - 2 回目：「Sign in with ChatGPT」を選び、ChatGPT のアカウントでログインします。
   ログインが終わったら黒いウィンドウに戻ると、自動で続きが進みます。

4. オプション機能を 2 つ入れるか聞かれます。どちらも Enter（Y）がおすすめです：
   - PDF / Word / Excel の読み取り（約 60 MB）
   - iPhone の写真（HEIC）対応（約 100 MB）

5. 「すべて完了しました！」と出たら完了です。アプリが自動で開き、
   デスクトップに「デュアルAIチャット」のアイコンができます。


【普段の使い方】
- 起動：デスクトップの「デュアルAIチャット」をダブルクリック（またはフォルダ内の start.vbs）。
- 質問：「Claude だけ」「Codex だけ」「両方に聞いて比較」を選んで Enter で送信。
- 添付：画像・スクリーンショット・iPhone の写真・PDF・Word・Excel・CSV をウィンドウにドラッグ、
  またはスクリーンショットを Ctrl+V で貼り付け。
- 履歴：左側で日付別（カレンダー付き）・トピック別に過去の会話を探せます。検索もできます。
- 表示言語：左下で 中文 / 日本語 / English を切り替えられます。


【困ったときは】
- エラーや途中でネットが切れた：もう一度 install.bat をダブルクリック。足りないものだけ入れ直します。
  ログは data\install.log にあります。
- 「ログインしていない」「ログイン期限切れ」と出る：もう一度 install.bat を実行するとログイン画面が開きます。
- バックグラウンドサービスの停止：画面左下の「設定と接続」→「バックグラウンドサービスを停止」。
- アンインストール：サービスを停止してから、フォルダごととデスクトップのアイコンを削除します。
  （ログイン情報は C:\Users\<ユーザー名>\.claude と .codex にあります。不要なら削除してかまいません。）


【プライバシー】
会話・添付ファイル・比較レポートはこのフォルダの data にだけ保存され、ほかには送信されません
（質問の内容は、回答のために Claude / ChatGPT に送られます）。
